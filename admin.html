使い方・トークンの作り直し方（忘れたらここを見る）

ふだんの更新

  1. 作品やサイトの内容を、下の欄で書き換える（サムネ・タグ・段落・動画も足せます）
  2. いちばん下の「公開する」を押す
  3. 1〜2分待つと、サイト（トップのページ）に反映される

トークンの期限が近づいたら（作り直し）

  1. GitHubを開いて、右上のアイコン → Settings → いちばん下の Developer settings → Personal access tokens → Fine-grained tokens
  2. 古いトークンを開いて「Regenerate token」を押すか、「Generate new token」で新しく作る
  3. 新しく作る場合：Token name は何でもOK、Expiration は30日、Only select repositories で tomochiradio.github.io だけ選ぶ
  4. Permissions → Add permissions → Contents を Read and write にする
  5. 「Generate token」を押して、出てきた github_pat_ から始まる文字列をコピーする（画面を閉じると二度と見られません）
  6. このページの「GitHubとつなぐ」を開いて、トークンの欄に貼り付け、「保存して読み込む」を押す。期限の日付は、GitHubの画面に出ていた日付に直す
トークンは、このブラウザの中にだけ保存されています。別のパソコンやスマホで開くと、もう一度入力が必要です。チャットやSNSには、貼らないでください。
GitHubとつなぐ（最初に1回だけ） トークンは、このブラウザの中だけに保存されます。リポジトリ1つだけに「Contents: Read and write」を許可した、細かい権限のトークンを作ってください。 トークンを入れ替えると、「入れてからの日数」は、今日から数え直します。
